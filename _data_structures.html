Arrays will be our first real exploration of the idea of data structures. Data structures are ways of organizing and storing data so that we can use them more efficiently. Data structures are a fundamental part of computer science, and they are used in almost every program we write. Arrays aren’t necessarily the best data structure for every situation, but they are a good place to start.

9.1. Arrays and Indexes

The variables we’ve used to this point can only store one piece of data at a time, and sometimes we need to store more than that. For example, we might need to store a list of cities in a band’s world tour. I could create a variable for each city, but that would be a lot of variables to keep track of. Arrays give us a way to store multiple pieces of data as a single collection.

Each individual value in an array can be referred to as an element. Each element in an array has a unique index that tells us where it is within the array. The number of elements in an array is called the length of the array. The first element in an array has an index of 0, the second element has an index of 1, and so on. The last element in an array is always the length of the array minus one. If our grocery list has 5 items, the indexes of the items would be 0, 1, 2, 3, and 4.

9.2. Defining and Using Arrays

In C#, arrays are objects, so they have to be created with the new keyword, and array identifiers use square brackets [ and ] to specify index numbers.

Any time you see square brackets in C#, you’re dealing with an array.

The syntax to declare and initialize an array is as follows.

1
string[] tourStops = new string[5];

This code creates an array of string objects called groceryItems that can hold 5 elements.

Once we have an array, we can assign values to its elements using indices (or, as normal people would say, indexes), which are placed in square brackets after the array name:

1
2
3
4
5
tourStops[0] = "Phoenix";
tourStops[1] = "San Diego";
tourStops[2] = "Denver";
tourStops[3] = "San Francisco";
tourStops[4] = "Los Angeles";

Each element in the array is assigned a value, and the index is used to specify which element is being assigned.

Once we have values in an array, we can access them using the index. The element is just like any other variable, so we can use it in expressions, pass it to methods, and so on.

Example 9.1 - Accessing and modifying array elements by index.
1
2
3
4
Console.WriteLine("The first item on the list is " + tourStops[0]);
Console.WriteLine("The last item on the list is " + tourStops[4]);
tourStops[2] = "New York City";
Console.WriteLine("The third stop has been changed " + tourStops[2]);

When using arrays, we have to be careful to stay within the bounds of the array—the upper and lower limits of the array indexes. If we try to access an element that doesn’t exist, we’ll get a System.IndexOutOfRangeException. This is a runtime exception, so it won’t be caught by the compiler, and it will cause our program to crash. The lower bound of an array is always zero, so any index less that 0 is out of bounds. The upper bound is always the length of the array minus one, so any index greater than or equal to the length of the array is out of bounds. In our tour cities example, any index greater than 4 would be out of bounds.

9.3. Traversing Arrays

Working with individual elements in an array can be useful, but to really see the power of arrays, we need loops. With a loop, we can easily move through an array and perform some task or operation on each element. For example, if we have an array of quiz scores, we could use a loop to add up all the scores and calculate the average.

When we use a loop to go through an array, we are traversing the array. To traverse an array means to go through each element in the array, one at a time, and do something with it. We can use a traversal to put values into an array (which we call populating the array), to modify values in an array, or to read values from an array. We can also use a traversal to search for something within an array, or to put the elements in some kind of order.

Most of the time, we’ll use a simple for loop to traverse an array.

Example 9.2 - Using a for loop to traverse an array
1
2
3
4
5
6
7
int scores[] = {90, 85, 95, 88, 92};
int sum = 0;
for (int i = 0; i < scores.Length; i++)
{
    sum += scores[i];
}
Console.WriteLine($"The sum of the scores is {sum}");

In this example, we have an array of quiz scores. We use a for loop to go through each element of the array and add it to the sum variable. Using a variable like sum to accumulate a value is a common pattern in programming, and we refer to such as variable as an accumulator. Notice that we declare and initialize it before the loop, and then we update it inside the loop. If we declare it inside the loop, it will be reset to zero each time the loop body runs, and we won’t get the correct sum. It also wouldn’t be accessible outside of the loop due to its scope.

At this point, clever or resourceful students point out that we could just call a method on the array to calculate the sum: scores.Sum(). Sure, and that’s what you will do in your life beyond this course. But since we’re learning about loops, that would defeat the point. My assignments for this chapter assess your ability to write loops, so you won’t get any points for code that doesn’t at least try to traverse the array.

In the example, notice that we use the Length property of the array to set the loop condition. That way, this same loop will work for any array of any size. If we hard-coded the size of the array into the loop, we would have to change our code every time we changed the size of the array.

Example 9.3 - A for loop unwisely using a "hard coded" literal for the array length
1
2
3
4
5
6
7
int scores[] = {90, 85, 95, 88, 92};
int sum = 0;
for (int i = 0; i < 5; i++)
{ // Uh oh! What if we decide to hold more scores?
    sum += scores[i];
}
Console.WriteLine($"The sum of the scores is {sum}");

9.4. Putting Objects in Arrays

In C#, an array can hold a primitive type, like an int, or an object. We’ve been using arrays of strings, which are objects, but students sometimes don’t realize that they can also create arrays of objects they define themselves.

If we were to define a GroceryItem class with fields for the name and the aisle where it’s located, we could create an array of GroceryItem objects.

Example 9.4 - Creating and populating an array of objects
1
2
3
4
5
6
GroceryItem[] groceryItems = new GroceryItem[5];
groceryItems[0] = new GroceryItem("milk", 4);
groceryItems[1] = new GroceryItem("eggs", 9);
groceryItems[2] = new GroceryItem("bread", 7);
groceryItems[3] = new GroceryItem("butter", 4);
groceryItems[4] = new GroceryItem("cheese", 4);

Putting objects in an array expands the possibilities of what we can do with arrays. Our array can hold multiple objects, and each object can have multiple fields—this allows arrays to manage large amounts of data in a single collection.

9.5. foreach Loops (Optional)

Because array traversal is such a common task, C# provides a keyword that makes it easier to write a traversal loop: foreach. A foreach loop is easy to write, and because it handles index management for us, it is less error-prone than a traditional for loop. However, it is less flexible than a traditional for loop: we can’t use it when we need to know the index of the element we’re working with, or when we need to move through the array in a different order.

The foreach loop is optional. You can always use a traditional for loop to traverse an array, and you’ll need to know how to do that for the assignments in this chapter. None of our assignments require the use of a foreach loop.
Example 9.5 - Using a foreach loop to traverse an array
1
2
3
4
5
6
7
int[] scores = {90, 85, 95, 88, 92};
int sum = 0;
foreach (int score in scores)
{
    sum += score;
}
Console.WriteLine($"The sum of the scores is {sum}");
